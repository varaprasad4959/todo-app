# My To-Do App

A simple task management web application built with Python and Flask.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Clear completed tasks
- Task statistics
- SQLite database
- Responsive design

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
